# Projetos em C# (Windows Forms)

Aplicações desktop desenvolvidas nas aulas de Engenharia de
Computação, praticando interface gráfica, validação de dados
e eventos em C#.

## Projetos
- **Sistema Biblioteca** — controle de empréstimo de livros com
  validação de prazo
- **Check-in Hotel** — cadastro de hóspedes
- **Sistema Lanchonete** — pedidos e cálculo de total
- **Cadastro Clientes** — cadastro com validação de campos
- **Gerenciador de Tarefas** — lista de tarefas com status
- **MidiaApp** — reprodução de mídia

## Como abrir
Abra o arquivo `.slnx` de cada projeto no Visual Studio e
pressione F5.
