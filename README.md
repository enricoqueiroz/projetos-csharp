# Projetos em C# (Windows Forms)

Aplicações desktop desenvolvidas para praticar interface gráfica, manipulação de componentes, validação de dados e eventos em C# utilizando Windows Forms.

## Projetos
- **Bloco de Notas** — editor de textos simples com recursos de manipulação de arquivos
- **Check-in Hotel** — sistema de cadastro e gerenciamento de hóspedes e estadias
- **Sistema Biblioteca** — controle de empréstimo de livros e gerenciamento de acervo
- **Cadastro Clientes** — formulário para cadastro e validação de dados de clientes
- **Calculadora Visual** — calculadora interativa com operações aritméticas básicas
- **Contador de Cliques** — aplicação simples de eventos de clique e atualização de interface
- **Conversor de Moeda** — conversor de valores monetários com taxas de câmbio

## Como abrir
Abra a solução (`.sln` ou `.slnx`) de cada projeto no Visual Studio e pressione `F5` para executar.
